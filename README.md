# Battery-AI 🔋

Battery-AI is an intelligent battery health and diagnostic assistant powered by Python, Streamlit, and Groq AI.

## Features

- Battery health assessment
- Battery capacity health calculation
- Charging and load analysis
- Battery symptom analysis
- Rule-based safety warnings
- AI-generated diagnostic report
- Downloadable diagnostic report
- Supports automotive and industrial battery applications

## Technologies Used

- Python
- Streamlit
- Groq API
- Large Language Model
- HTML and CSS

## How the Application Works

1. User enters battery information.
2. Python validates the entered data.
3. The application calculates basic battery health indicators.
4. Safety rules identify possible warnings.
5. Groq AI generates a diagnostic report.
6. The user receives recommendations and safety guidance.
